## 仕様（実物で確認した事実）

- 商品の正本は公式メニュー1ページ `/menu/`（セクション7つ・全43件、2026-11-27実測）。セクションは id 属性（limited / kakedashi / tsukedashi / okonomi / gohan / other / takeout）で区切られ、カテゴリー名は見出しから取る。HTMLコメントに販売終了した旧商品が残っているため解析前にコメントを除く。
- 価格はサイズ別（小・中・大）。一覧ではうどん系は「小」の価格だけ（「円～」）、サイド系は単品価格。期間限定セクションだけは一覧に全サイズの価格が載る。全サイズ価格とサイズ別 kcal は詳細ページ（`NN_N.html`）にある。
- 商品IDは詳細ページのファイル名。詳細リンクには相対（`02_2.html`）と絶対（`/menu/01_10.html`）の2形式が混在する（玉とろぶっかけが絶対形式。試行巡回で発見して対応）。期間限定の商品には詳細ページが無いので、商品名から ID を作る（`campaign_` + 正規化した名前の sha1 先頭10文字）。当初はメニュー画像のファイル名を使う案だったが、モルのレビューで「画像名は枠ごとの使い回しで、次の季節の商品が同じ ID になって既存の記録を上書きする」と指摘があり、実物でもコメント内の旧商品が同じ画像名を使っていることを確認して、名前由来に変更した（同じ商品が次の季節に戻れば同じ ID になり、再発売として同じ記録に付く）。「同じ画像名でも名前が違えば別の ID になる」テストも追加した。
- 発売日は自社ニュース記事が正本（やよい軒方式）。商品記事の「商品価格」（商品名＋サイズ別価格）と「販売期間」から取り、販売期間の開始日を発売日、終了側の表記を planned_end_text にする。実物の商品概要は dl で、テキスト化すると見出しと中身が同じ行にくっつく（「商品価格鴨ねぎうどん（温）」）ため、「商品価格」以降のテキストを行分割して読む。定期券のような販促記事には「商品価格」が無いので商品記事とみなさない（実物の定期券記事・フェス記事で None になることを確認）。
- robots.txt は `/test/` のみ Disallow。自動取得の禁止条文は無い（2026-11-27確認）。

- 定番のサイズ別価格と kcal は初回記録時のみ取得する。2回目以降は一覧の「小」価格しか更新できない（丸亀と違い、一覧に全サイズが出ないため）。
